# Assemble a payment evidence pack

Create a review record with the invoice status, each finding, its owner, the next step, and the supporting document IDs.

Open the [AP Payment Review repository](https://github.com/assafsela-ai/ap-payment-review#use-the-agent-skills) as a project in Codex or Claude Code. The sample workflow uses Node.js 22 or newer.

- **Codex** `$assemble-payment-evidence`
- **Claude Code** `/assemble-payment-evidence`

Try this request in the sample project.

> Build the evidence pack for the sample invoice. Include only the late goods receipt and explain which check is still open.

[Live demo](https://assafsela-ai.github.io/ap-payment-review/) · [Skill source on GitHub](https://github.com/assafsela-ai/ap-payment-review/blob/main/skills/assemble-payment-evidence/SKILL.md)
