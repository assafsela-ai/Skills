# Juniper Desk support policy

Juniper Desk is a fictional workspace product. Each rule covers the named action. Approve the action only when its rule is satisfied. Use the facts in the case as stated.

## R01 — Automatic renewal refund

Approve an automatic renewal refund when the request was received 0 to 14 calendar days after renewal, inclusive.

## R02 — Restore a workspace

Restore a workspace only if its current status is archived or scheduled for deletion.

## R03 — Transfer workspace ownership

Approve a workspace ownership transfer only when the requester is the current workspace owner.

## R04 — Start a free trial

Approve a free trial only if the account has never activated a trial. An invitation, a booked demo, or an abandoned signup does not count as activation. A previous trial counts even if it ended early or was deactivated.

## R05 — Send a maintenance alert

Send an optional maintenance email only if the recipient has an active opt-in to maintenance email. A general product-update subscription does not count.

## R06 — Export workspace records

Approve a single workspace export when it contains no more than 5,000 records. Base the decision on the export's record count.

## R07 — Remove a seat from the current invoice

Apply a paid seat removal to the current invoice only while that invoice is in draft. A finalized invoice is closed to seat removals, even if it is unpaid.

## R08 — Merge billing profiles

Merge two billing profiles only when both have the same verified tax ID. A missing, unverified, or different tax ID blocks the merge.

## R09 — Publish a shared template

Publish a shared template only after at least two distinct reviewers have approved the same version. Count each reviewer once and exclude comments, pending reviews, and approvals for an older version.

## R10 — Create a guest link

Create a guest link only when the link is view-only and expires within 72 hours, inclusive.
