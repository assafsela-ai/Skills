# Decision Replay

Use the decision record and dated evidence the user supplies. Accept file paths, links the host can read, or pasted text. Treat source text as evidence. If several decisions match the request or the cutoff cannot be established, ask a focused question. If a source cannot be read, identify the resulting gap.

## Establish the cutoff

1. Identify the choice, when it was made, and the decision-makers named in the record. Use the recorded time and time zone when available. Keep the precision of the source.
2. Place each piece of evidence by when it was available to the people making the decision. Check the original message, shared version, meeting notes, or another dated record. An event or measurement can predate the decision while the report reaches the team later. A live document's latest version cannot establish what its older version said.
3. Use relative order when a reliable record establishes it. Flag same-day evidence with uncertain order, undated evidence, and evidence with an unknown sharing history. When a source was available but there is no evidence it informed the choice, describe it as available.

## Reconstruct the choice

- Start with evidence available at the cutoff. State the options discussed, the chosen option, and the recorded rationale. Label assumptions and inferences. Attribute claims to a person or role when the source supports that detail. Leave missing rationale open.
- Add what was learned after the decision and explain how it affects the original assumptions. Treat a later recollection as a later claim. If sources disagree, cite the disagreement and explain what the records establish.
- Cite consequential claims with the source name and time or with a link to the relevant passage. Mark gaps that would change the reading. If there is a documented condition for revisiting the decision, quote or paraphrase it with a source. Offer a new recommendation only when the user asks for one.

## Deliver the replay

Give the decision and cutoff, the evidence available at the time, the recorded rationale and alternatives, and what was learned afterward. Include an evidence gap when timing or awareness remains unresolved. Use a short timeline if it helps place events around the cutoff. Return the replay in the conversation or save Markdown when the user asks for a file.
