# Meeting room booking

Employees need a way to find and reserve meeting rooms at the office.

## Find a room

Employees search by date, time slot, and minimum capacity.
Results show only available rooms and display each room's name and capacity.
If no room matches, the results show a message asking the employee to change the search.

## Reserve a room

An employee can reserve a room from the search results.
The confirmation shows the room name, date, and time slot.
If someone else reserves the room first, the employee sees a message and can return to the results.

## Cancel a reservation

Employees can cancel their own reservations up to 30 minutes before the start time.
When a reservation is cancelled, the room becomes available again for that time slot.

## Reminders

Employees should receive a reminder before the meeting.
