# Skills

Reusable skills for Codex, Claude, and other tools that support Agent Skills.

- [Spec to Backlog](spec-to-backlog/) turns a product spec into editable user stories with acceptance criteria, source references, and CSV export.
- [AI Workflow ROI Calculator](ai-workflow-roi-calculator/) compares automation costs, break-even volume, payback, and ROI. It includes live sliders. [Open the browser calculator](https://assafsela-ai.github.io/Skills/ai-workflow-roi-calculator/assets/).
