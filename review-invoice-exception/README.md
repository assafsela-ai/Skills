# Review an invoice exception

Compare an invoice with its purchase order and goods receipts. Report uncovered units, price differences, and the records that support each finding.

Open the [AP Payment Review repository](https://github.com/assafsela-ai/ap-payment-review#use-the-agent-skills) as a project in Codex or Claude Code. The sample workflow uses Node.js 22 or newer.

- **Codex** `$review-invoice-exception`
- **Claude Code** `/review-invoice-exception`

Try this request in the sample project.

> Review the sample invoice and explain why the first receipt covers only 80 of the 100 billed units.
