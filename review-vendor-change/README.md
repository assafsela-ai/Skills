# Review a vendor bank change

Compare the requested account with the approved vendor record. Identify the verification evidence that is present or still missing.

Open the [AP Payment Review repository](https://github.com/assafsela-ai/ap-payment-review#use-the-agent-skills) as a project in Codex or Claude Code. The sample workflow uses Node.js 22 or newer.

- **Codex** `$review-vendor-change`
- **Claude Code** `/review-vendor-change`

Try this request in the sample project.

> Review the new bank details in the sample invoice. Then include the fictional callback record and explain what changed.
