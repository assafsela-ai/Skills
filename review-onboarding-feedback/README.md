# Review Onboarding Feedback

Group onboarding survey responses or interview notes into themes. Cite the feedback and propose changes for the onboarding plan owner to review.

## Install

1. [Download the Review Onboarding Feedback ZIP](https://assafsela-ai.github.io/people-onboarding-lab/downloads/review-onboarding-feedback.zip).
2. For Codex or Claude Code, extract the ZIP so `SKILL.md` is at the project path below. Open a new session from the project root and invoke the skill.

| Tool | Path to `SKILL.md` inside your project | Invoke |
| --- | --- | --- |
| Codex | `.agents/skills/review-onboarding-feedback/SKILL.md` | `$review-onboarding-feedback` |
| Claude Code | `.claude/skills/review-onboarding-feedback/SKILL.md` | `/review-onboarding-feedback` |

For Claude in the browser, upload the ZIP under **Customize → Skills** and enable it. Attach the feedback and current plan and ask Claude to use Review Onboarding Feedback.

## Try it

Provide [the sample survey responses](https://assafsela-ai.github.io/people-onboarding-lab/samples/onboarding-feedback.md) and [the revised plan](https://assafsela-ai.github.io/people-onboarding-lab/samples/plan-v2.md). Ask which onboarding tasks should change, which responses support each proposal, and how the owner can tell if the change helped.
